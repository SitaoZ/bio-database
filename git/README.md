# Git

## Github

### Codespace
当你通过浏览器使用 Codespace 时，自动保存功能是默认开启的，并保存到云端；但Codespace本身是一个临时的开发环境，如果它被删除了，里面的所有未提交的改动都会丢失。
因此，把代码提交并推送到 GitHub 仓库，才是真正永久保存的唯一方法
- 方式一：使用VS Code的图形界面（推荐新手）  

1. 在 Codespace 左侧活动栏点击 源代码管理 图标（像一棵树的分支）。
2. 在“更改”列表中，看到你修改过的文件。点击文件右侧的 + 号，将它们“暂存”起来。
3. 在上方的输入框里，写一句清晰的说明，描述你这次做了什么修改（例如“修复了登录页面的样式bug”）。
4. 点击 提交 按钮（如果有下拉菜单，可以选择“提交并推送”一步到位）。

- 方式二：使用终端命令（Git 标准流程）  
如果你习惯命令行，可以在 Codespace 的终端中直接操作：
```bash
# 1. 将当前目录下的所有改动添加到暂存区
git add .

# 2. 将暂存区的改动提交，并附上说明
git commit -m "这里写你的修改说明"

# 3. 将本地的提交推送到远程 GitHub 仓库
git push
```
